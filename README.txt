Workshop Bisa AI — Website Cerah

Buka dist/index.html untuk melihat website, atau unggah seluruh isi dist ke hosting statis.

Alur funnel: perhatian → kebutuhan → materi FAB → pengalaman → demo → kecocokan peserta → jadwal → penawaran → formulir → FAQ.

Fitur: filter kota, pemilihan sesi otomatis, jumlah peserta 1–6, kalkulasi total, validasi formulir, ringkasan pendaftaran WhatsApp, video YouTube, FAQ, menu mobile.

Sebelum digunakan untuk promosi sendiri, sesuaikan nama brand, foto, harga, jadwal, dan nomor WhatsApp. Data saat ini mengikuti situs referensi akademisiapai.my.id yang diperiksa pada 26 Oktober 2026. Tidak ada pembayaran otomatis, penyimpanan data server, atau penerbitan tiket. Form menyiapkan pesan WhatsApp; pengunjung mengirimnya sendiri.

Pemeriksaan: sintaks JavaScript; pratinjau mobile; filter Bekasi; pilihan sesi diteruskan ke formulir; total 2 peserta Rp350.000. Pengiriman pesan tidak dilakukan saat pengujian.
